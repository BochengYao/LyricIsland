# 彩蛋歌曲页面

路由：`/songs/`、`/zh-hant/songs/`、`/en/songs/`、`/ja/songs/`。

当前页面沿用官网暖灰、橙色强调与悬浮导航，内容为：抽一张今日彩蛋、紧凑歌单、可视猜歌、客户端触发步骤。

## 当前功能

- 抽唱片：点击揭晓歌曲与真实彩蛋名称，可再抽，连续两次不重复。
- 歌单：13 首歌曲，支持歌名、歌手别名和彩蛋名称搜索；无分类、收集按钮和行内操作。整行是可用键盘操作的按钮，点击在 songs 当前页面背景播放对应彩蛋。桌面行高约 64px，小屏约 60px，长文本自然增高。
- 猜歌：在独立深色画面中直接呈现对应彩蛋动画，三选一、揭晓、计分、下一题。答案揭晓前显示画面，不用抽象名称替代视觉线索；画面提供屏幕阅读器文字描述。两首圣诞歌曲共享雪花效果，出题排除相同效果的干扰项，保证选项只有一个有效答案。
- 每段线索播放 5 秒后停帧，作答也会停帧；支持「再看一次」、系统减少动态的静态呈现、加载失败后的重试和文字备用线索。

已移除覆盖正文的全页彩蛋、DOM 硬遮挡、网页彩蛋展示菜单、导航栏播放/暂停/关闭按钮、抽卡展示入口、复制歌名、收集册与本机存储逻辑、分类，以及客户端匹配/画质/版本目录说明。原有浏览器记录不读取、不改写。

歌单支持同页背景预览：`SongEffectBackground` 与猜歌共用效果渲染器，Canvas 位于正文下层，粒子使用网页文档坐标，随正文滚动。绘图缓冲区保持可视区大小，通过滚动偏移绘制相应区域，避免创建整页高度的大画布，透明背景、一般效果使用 65% 整体不透明度，无 DOM 硬裁切。雪花在浅色底上使用原始粒子透明度（不再额外降低整层透明度），并加淡蓝灰投影边缘以保持可见；不改原始 SVG、填色或运动规则，猜歌深色画面不应用此处理。点击歌曲播放，点击另一首切换；再次点击当前歌曲或页面空白处直接取消预览，Esc 同样停止。取消后立即清除选中样式，并在约 160ms 内淡出；不保留暂停状态或左侧橙色条。出现同样使用 160ms 淡入，切换时等待新场景准备好后交叉淡化，淡出完成再释放渲染器；快速切换丢弃过期加载，最多保留两个已绘制层与一个待加载层。系统减少动态设置下取消渐变。没有 dialog、新页、遮挡正文的深色幕布、滚动锁或焦点约束。搜索、导航、抽歌和猜歌等控件不触发背景暂停。页脚与导航保持在背景上方。支持系统减少动态和加载失败后重新点击歌曲重试。提示「点击歌曲预览彩蛋🎉」宽屏位于标题右侧，窄屏或竖屏位于标题下方。

## 客户端事实来源

歌曲、效果参数与 19 个 SVG 来自 `v3.7.2-beta` 发布源（提交 `617949231a83332d24a1b8f4dd42b54aaf9730bc`）的 `LyricHover.App/Assets/SongEffects/catalog.json` 和同目录素材，完整保存在 `data/song-effects-catalog.json`。`data/song-effect-facts.json` 按效果类型与素材组合定义四语事实名称，抽卡、歌单、猜歌揭晓共用。

`lib/song-effect-scene.ts` 在 Canvas 中保留客户端六个 WPF 渲染器对应的八类运动公式：飘落、纸页翻转与卷曲、24 段蛇身爬行、雨丝、星体漂移、红色霓虹横移、蝙蝠振翅、双环烟花。使用原素材、原配色、尺寸、透明度、速度与旋转参数。场景以自身尺寸为边界，初始铺开目标粒子数以便立即识别；不查询或裁切页面正文，除场景外边界外不使用遮罩。

来源记录在 `data/song-effect-source.json`，包括六个渲染器、宿主及匹配器的八份 C# 文件 SHA-256。核对脚本能发现目录、素材或原渲染源码的变化。浏览器 Canvas 与 Windows WPF 尚未做实机逐帧像素等价验证。
