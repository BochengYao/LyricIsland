# V3 路线图

## 版本基线

- V3 桌面开发基线为 `3.0.0-Beta`，用户可见名称写作 `v3.0.0 Beta`。
- 只有通过规定门禁并成功生成的可测试候选才递增补丁位；首个任务栏歌词候选为 `v3.0.1 Beta`。
- `tools/publish-next-version.ps1` 是唯一候选生成入口；`-KeepVersion` 只能复现已有候选，不能生成新候选。
- V3 继续保留 Store 包身份、应用 ID、单实例名和旧用户数据迁移路径。正式发布前由发布线程另行移除 `Beta` 后缀。

## 任务栏歌词首版边界

- 使用商店兼容的独立任务栏浮层，不注入或替换 Explorer 组件，不把 Windows Widgets provider 误作任务栏歌词入口。
- 默认关闭；首次开启必须说明将暂时隐藏系统小组件，且该设置是当前用户的全局任务栏设置。
- 顶部歌词岛与任务栏歌词是独立开关，可以同时显示；显示屏沿用现有 `ScreenName` 选择。
- 任务栏歌词消费 App 层同一份 `LyricsPresentationSnapshot`，不得增加第二套媒体轮询、歌词解析、网络请求或缓存。
- 只支持 Windows 11；目标屏幕没有任务栏、无法可靠定位、安全宽度不足或系统设置写入/刷新失败时必须拒绝启用并恢复原状态。
- 本轮不实现逐字歌词、播放控制、自定义任务栏宽度或其他 V3 路线图能力。
- 本阶段只允许生成本地可测试候选，不上传或提交 Microsoft Store。

## 验收门禁

- Release 构建与同一构建产物的桌面测试通过；既有失败与新增回归分开报告。
- 版本递增、失败回滚和并发互斥均有自动测试证据；About、文件版本和 MSIX 四段版本保持一致。
- Windows 11 实机覆盖居中/左对齐任务栏、主副屏、DPI、自动隐藏、Explorer 重启、全屏窗口和安全空间不足。
- `TaskbarDa` 原值不存在、为 `0`、为 `1` 时，手动关闭、正常退出、异常退出后的下次启动都能精确恢复。
- 单行、多行、翻译、无可靠译文、超长歌词、切歌、暂停和无播放状态与顶部歌词岛保持一致，且不产生重复歌词请求。
