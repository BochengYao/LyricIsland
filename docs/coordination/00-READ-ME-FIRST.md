# 协作入口

本目录是 LyricHover 的线程协作单一入口。新线程先读本页，再读自己的章程；未满足前不得修改代码或共享文档。

## 启动顺序

1. 阅读 [线程总目录](01-THREAD-DIRECTORY.md)，确认任务归属。
2. 阅读对应 `charters/` 文件、[所有权规则](03-OWNERSHIP-RULES.md) 和任务涉及的共享文档。
3. 在交接记录中声明任务、基线提交、允许修改的目录与验证方式。
4. 只在章程授权范围内实现；跨范围需求交回项目统筹线程。
5. 完成后按 [交接模板](templates/HANDOFF.md) 新建一份记录。

## 规则

- 章程、总目录、文档注册表、所有权规则和决策页对模块线程为只读；仅“项目统筹与架构”线程可修改。
- 本仓库不预建空闲 Codex 子线程。出现明确任务时，以对应章程为首要上下文创建短期线程。
- `main` 必须可发布；功能工作使用短期 `codex/feature/<domain>-<task>` 分支，不以永久分支代替模块边界。
