- 配套示意：本任务书已完整写入中英文字体、字号、凹凸半径、胶囊形和恢复默认半径的要求。

## 任务目标

在现有“设置 → 歌词外观 → 歌词岛”中增加字体、字号和岛体轮廓配置。用户能分别选择中文字体和英文字体，调整歌词字号；能分别调整凹角与凸角半径，将上方凹角切换为凸角形成胶囊形，并一键恢复默认半径。

保留现有歌词、逐字跟随、布局编辑、鼠标交互和默认外观行为。设置仅改变展示，不改变歌词数据、时间线、播放器或任务栏歌词坞。

## 功能要求

### 1. 中英文字体

- 增加独立的中文字体与英文字体选择器，从本机已安装字体中选择；两项互不覆盖。
- 中文字符及中文标点使用中文字体；拉丁字母、英文标点和数字使用英文字体。
- 中英混排时在同一歌词行内按字符类别应用字体，不改变原字符串、字符索引、歌词时间戳或逐字跟随顺序。
- 日文、韩文、符号、表情及所选字体缺少的字形按系统字体回退显示；不可用字体不得造成空白或方框字。
- 翻译复用相同的中英文字体配置。主歌词与翻译字号默认沿用现有字号关系；若提供独立翻译字号，必须由用户显式开启。

### 2. 歌词字号

- 提供数值输入和滑块，使用 DIP；设计建议范围为 10–48 DIP，默认值与当前歌词外观一致。
- 输入超出范围时规范化到允许边界；键盘输入、步进、滑块、预览、实际岛体和重启后的值保持一致。
- 字号变化不得改动歌词同步、高亮时间或内容；重新测量排版后正确更新布局。

### 3. 凹凸角和半径

- 默认保持现有轮廓：上方两角内凹、下方两角外凸。
- 提供凹角半径和凸角半径两个独立数值；上方角型可在“凹角 / 凸角”间切换，默认成对切换。
- 凸角模式下，上下角半径满足当前高度的一半时呈胶囊形；半径随岛体尺寸变化正确归一，不产生尖刺、自交或间隙。
- 第一版按左右成对设置上方角型及上下凹凸半径；单个角分别设置不作为必需项，可在实现中复用现有模型时评估，但不得拖延核心验收。
- 增加“恢复默认半径”按钮：凹角、凸角半径恢复为能复现当前默认轮廓的产品默认值；按钮只重置半径数值，不改变当前上方凹/凸模式。
- 设置页预览与实际岛体使用同一几何结果；背景、裁剪、阴影和命中测试一致。

### 4. 设置体验与兼容

- 直接在当前“设置 → 歌词外观 → 歌词岛”设置列表中新增“中文字体”“英文字体”两行，并将字号、角型、凹角半径、凸角半径和“恢复默认半径”放在同一现有列表区域内。
- 复用当前设置列表、卡片、滚动和预览机制；不新开设置页、弹窗或折叠分区，不重做设置窗口。
- 继续沿用当前 220 ms 防抖即时提交、设置运行时协调器和窗口关闭时刷新待提交修改的行为。
- 新增设置采用兼容的可选持久化字段。旧配置缺失字段时，默认使用现有字体、字号和凹上凸下轮廓。
- Apply 后以运行时协调器返回的有效设置为准；应用重启后恢复最近一次已提交配置。
- 恢复默认半径仅影响半径字段，不重置字体、字号、歌词行数、翻译开关、上方角型或其他偏好。

## 实现边界

允许修改：

- `LyricHover.App/` 设置模型、设置页面、设置协调器消费路径、歌词岛形状绘制及歌词文字模块渲染。
- `LyricHover.Tests/Program.cs` 中与本功能对应的设置、几何和混排回归。
- 本功能的独立设计和交接文档。

不得修改：

- `LyricHover.Core/` 歌词解析、时间线、播放状态或缓存语义。
- LyricDock 的外观、窗口、任务栏定位和生命周期。
- Store 身份、单实例名、数据迁移兼容层、发布脚本、版本号及发布产物。
- 当前工作区中与本任务无关的未提交网站、商店、宣传资产和其他 WIP。

## 验收标准

1. 旧设置文件首次升级后外观与升级前一致；新字体、字号、角型和半径保存、关闭、重启后值一致。
2. 中文、英文、数字、中英混排、中文/英文标点、双行歌词和翻译均正确应用字体；缺失字体和缺失字形有可读回退。
3. 字体变化、字号边界值、混排测量和逐字跟随高亮正常；歌词索引和时间戳语义没有变化。
4. 默认上凹下凸轮廓、调整凹/凸半径、上方切换凸角、胶囊形及恢复默认半径均可见且连续；默认半径按钮保留角型模式。
5. 实际岛体与设置预览几何一致；轮廓、裁剪、阴影、命中区域、拖动和悬停行为一致。
6. 在 100%、150%、200% DPI，主屏/副屏、单行/多行、歌词岛展开/收起等代表场景下没有裁字、闪烁、漏点或透明边角残留。
7. 设置防抖提交、窗口关闭刷新、重启恢复、旧字段缺失默认、字体回退及半径边界有针对性回归覆盖。
8. Release 构建、同一构建的桌面测试和真实 Windows UI 验收分别记录；自动检查不能代替实机视觉与交互验收。

## 建议实现顺序

1. 为配置模型和设置运行时生命周期增加向后兼容字段及回归覆盖。
2. 实现中文/英文字体选择、混排文字渲染、字号调节和设置页预览。
3. 将当前岛体路径参数化，加入上角凹/凸切换、凹角/凸角半径及胶囊计算。
4. 加入恢复默认半径按钮并验证它只重置半径。
5. 完成高 DPI、多屏和实际窗口的 UI 验收，按桌面 UI 章程提交交接记录。
