## 01 歌词岛外观自定义

### 简体中文

标题：自由调整歌词岛的字体与轮廓

描述：歌词岛新增更完整的外观设置，可分别调整文字与岛体形状，让桌面歌词更贴合个人偏好。

分条（每行一条）：

```text
分别选择中文和英文字体，字体列表中可直接预览效果。
调整整体字体缩放，同时保留各模块原有的字号比例。
切换顶部凹角或凸角，并调整对应半径与屏幕边缘距离。
可一键恢复默认半径。
```

### 繁體中文

標題：自由調整歌詞島的字型與輪廓

描述：歌詞島新增更完整的外觀設定，可分別調整文字與島體形狀，讓桌面歌詞更符合個人喜好。

分點（每行一條）：

```text
分別選擇中文和英文字型，並在字型清單中直接預覽效果。
調整整體字型縮放，同時保留各模組原有的字級比例。
切換頂部凹角或凸角，並調整對應半徑與螢幕邊緣距離。
可一鍵還原預設半徑。
```
