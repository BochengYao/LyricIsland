# Microsoft Store 更新要点草稿 · 3.3.8

对应本地候选包：`store/package/msix/LyricHover_3.3.8.0_x64.msix`。以下四段分别用于商店的简体中文、繁體中文、English 和日本語更新说明；尚未提交商店。

## 简体中文

⚠️此版本修复了上版本可能崩溃的bug，强烈建议所有人更新！！

- 新增歌词岛外观自定义：可分别选择中英文字体、调整整体字号和顶部角型及半径；字体列表支持直接预览。
- 优化外观预览和模块布局编辑界面，调整预览宽度、控件间距及数值对齐。
- 修复右键歌词、拖动模块和调节布局设置时可能出现的崩溃；设置暂时无法保存时会提示并保留修改。
- 改进歌词坞在任务栏自动隐藏、全屏和右键菜单场景下的显示与位置恢复。

## 繁體中文

⚠️此版本修正了上一版本可能發生當機的問題，強烈建議所有人更新！！

- 新增歌詞島外觀自訂：可分別選擇中英文字型、調整整體字級及頂部角型與半徑；字型清單可直接預覽。
- 改善外觀預覽與模組版面編輯介面，調整預覽寬度、控制項間距及數值對齊。
- 修正右鍵點擊歌詞、拖曳模組及調整版面設定時可能發生的當機；設定暫時無法儲存時會顯示提示並保留修改。
- 改善歌詞塢在工作列自動隱藏、全螢幕及右鍵選單情境下的顯示與位置還原。

## English

⚠️ This version fixes crashes that could occur in the previous version. We strongly recommend that everyone update!

- Customize the lyrics island with separate Chinese and English fonts, overall text scaling, and top corner shapes and radii. Preview fonts directly in the font list.
- Improved the appearance preview and module layout editor, including preview width, spacing, and value alignment.
- Fixed crashes that could occur when right-clicking lyrics, dragging modules, or adjusting layout settings. If settings cannot be saved, your changes remain available to retry.
- Improved Lyric Dock visibility and positioning when the taskbar auto-hides, an app enters full screen, or a taskbar context menu opens.

## 日本語

⚠️ このバージョンでは、前のバージョンで発生する可能性があったクラッシュを修正しました。すべての方にアップデートを強くお勧めします！

- 歌詞アイランドの外観をカスタマイズできるようになりました。中国語・英語のフォント、全体の文字サイズ、上部の角の形状と半径を設定でき、フォント一覧で書体を直接確認できます。
- 外観プレビューとモジュール配置画面を改善し、プレビューの幅、項目間隔、数値の配置を調整しました。
- 歌詞の右クリック、モジュールのドラッグ、配置設定の調整時に発生することがあったクラッシュを修正しました。設定を保存できない場合も、変更内容を保持して再試行できます。
- タスクバーの自動非表示、全画面表示、右クリックメニュー使用時における歌詞ドックの表示と位置の復元を改善しました。
